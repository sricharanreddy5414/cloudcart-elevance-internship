# EverShop application notes

The running project stays on Windows. Do not copy `.env` files or the PostgreSQL volume into this directory.

When the Compose file is reviewed, record here:

- The image tag.
- The published ports.
- Whether port 5432 is exposed on the host.
- The volume name.
- Any password that must be rotated because it is a default or because it appeared in a terminal. Do not write the password itself.
